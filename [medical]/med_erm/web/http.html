<* -- HTTP entry of the dispatcher console (http://:/erm/). -- -- web/index.html, css and js are also client files (the in-game ui_browser -- loads them as a local CEF page), and MTA serves client files on their path -- with "application/octet-stream" - browsers then drop the stylesheet. So the -- HTTP page is sent as one document with the css / js inlined from the very -- same source files. local function read(path) local f = fileOpen(path, true) if not f then return "" end local content = fileRead(f, fileGetSize(f)) fileClose(f) return content end local page = read("web/index.html") page = page:gsub('', function() return "" end) page = page:gsub('', function(path) return "" end) httpWrite(page) *>
